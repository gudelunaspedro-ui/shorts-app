Política de Privacidade – Upload YouTube Shorts

Última atualização: 1 de novembro de 2026

O que é

O Upload YouTube Shorts é um script pessoal que roda apenas no computador do dono do canal e envia vídeos para o canal dele no YouTube.

Dados acessados

Com a autorização do usuário pelo login do Google (OAuth), o app usa os escopos youtube.upload e youtube apenas para:

  • enviar vídeos, títulos, descrições, tags e thumbnails ao canal do próprio usuário;
  • adicionar os vídeos enviados a uma playlist do próprio usuário, quando configurado;
  • consultar o status dos vídeos enviados por ele.

Armazenamento

O token de acesso fica salvo somente no computador do usuário (arquivo token.json). Nenhum dado é enviado a servidores de terceiros, vendido, compartilhado ou usado para publicidade. A única comunicação é com as APIs do Google/YouTube.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Basta também apagar o arquivo token.json do computador.
